# Fixed-reservoir five-run suite

## Goal

Measure how stable card and damage-family usage is across five independently generated fixed reservoirs for Kingdoms 001 and 009.

## Run

- Use pool seeds 1–5 for each kingdom and one shared evaluation seed per kingdom.
- Keep the existing 500,000-policy, 18,000 goldfish plus 2,000 random-tail protocol.
- Resume and deep-validate every pool and PSRO artifact independently.
- Reuse the exact Kingdom 009 seed-1 and seed-2 artifacts through an explicit preparation command.
- Report support plans, acquisition-based archetypes, continuous damage-family shares, per-card acquisition ranges, cumulative material coverage, reservoir overlap, runtime, and held-out five-by-five lottery cross-play.

## Interpretation

The report describes variation within the searched reservoirs. It does not prove global strategy coverage or card balance.
