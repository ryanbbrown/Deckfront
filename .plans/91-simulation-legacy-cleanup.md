# Simulation legacy cleanup

Status: implementation plan (direct mode; no plan panel; one implementation review).

## Goal

Remove every superseded simulation path. After this plan, the simulation surface is: the TS game engine and its Rust conformance reference, the Rust `hexdeck-goldfish` binary (goldfish, matrix, psro, verify commands and the JSON conformance protocol), the Goldfish-only Modal route v2, the local Matrix operation, the PSRO batch route, the v2 Rust balance report and classifier, the balance and smoke suites, and the playable game. Nothing else.

Timing: this runs inside the health-50 identity window, before any 50-health evidence exists, so scientific-allowlist deletions cost nothing extra. The base commit already contains the health-50 change and the deep-beam deletion.

## Decisions

Delete `modal/matrix_step.py` and `modal/test_matrix_step.py`. Full-route tests in `modal/test_native_strategy_search.py` go with their code.
